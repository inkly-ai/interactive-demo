# interactive-demo

Open-source interactive product demos. Capture screenshots or a screen
recording of your product, add hotspots and captions in a local editor, and
build a static demo you can host anywhere and embed with an iframe.

Work in progress. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Packages

| package | what it is |
|---|---|
| `packages/runtime` | the React player and the demo schema |
| `packages/cli` | `init`, `dev`, `capture`, `validate`, `build` |
| `packages/editor` | the local editor served by `dev` (bundled into the CLI, not published) |
